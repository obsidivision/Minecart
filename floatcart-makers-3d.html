About this view

Each maker is one straight track running south (x east, z south, y up, same coordinates as the schematics). The layout code has one token per rail: F flat, U slope up, D slope down, then r plain rail, p powered rail (on), h powered rail (off). S is a powered start rail with concrete behind it, and E the parking slope: a powered rail with no power, so it brakes the cart.

Where the cart stops on the parking slope sets its height, so it has to be right to 1×10−5 of a block. A depth-first search simulated about 3.6 million tracks; these 13 land inside the window. Every run is simulated with the same rules as the challenge build (rules page), and each was checked at 15 world positions in all 4 directions. Glass blocks are supports; the plain rails past each end only give the end slopes their shape.

Gold rails are powered rails: bright when on, dark when off. The outline around the cart is its 0.98×0.7 hitbox.
