How it works

A track is a straight line of rails. The cart rolls from the first rail and stops on the last one, an unpowered powered rail on a slope. How far up that slope it stops sets its height.

Physics
It matches FarCoolHat's stored cart exactly and was confirmed in game on 13 tracks.
x and z
Break the parking rail and the cart drops straight down, keeping its x and z.
Stoppers
Instead of placing the cart, you can stop it against a block or an amethyst bud so it settles on the start rail. Each stopper, and the side the cart comes from, gives a different starting spot, 16 in all. Try every stopper searches them all.
The launcher
Based on FarCoolHat's stopper. The cart runs off a powered slope, hits the stopper in mid-air and drops onto the start rail, so there's nothing to break. It's simulated but hasn't been tested in game yet.
Boat carts
You can't place a cart with a boat already in it, so it picks the boat up on the way, on the launcher or on a loading run. A cart with a passenger moves differently, so it gets its own results.
Where you build
Moving the track changes the last few digits. Check at 60 positions reruns it around the world in all four directions.
Keep it clear
A moving cart grabs mobs and boats it passes, which ruins the run. Keep the track clear and leave the experimental minecart changes off.
Downloads
The schematic on its own, or with command blocks that run the cart and post the result in chat.
